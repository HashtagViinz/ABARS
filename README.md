# ABARS (Aerial Building Abuse Recognition System)

ABARS is a Computer Vision project focused on Object Detection and Classification from a drone's perspective (UAV). It uses **YOLOv8** to automatically detect and classify building abuses, specific structures, and topographical features (e.g., buildings, quarries, landslides).

## 🚀 Features

- **Automated Dataset Parsing**: Automatically converts UAV JSON annotations to YOLO format and splits the dataset into `train`, `val`, and `test`.
- **Hyperparameter Tuning**: Built-in support for YOLO genetic algorithm tuning to find the best configuration for the UAVOD-10 dataset.
- **Seamless MLflow Integration**: Fully integrated with MLflow for tracking experiments, losses, and mAP metrics. Works flawlessly both locally and on SLURM clusters.
- **Smart CLI**: A user-friendly Command Line Interface to run tests, tuning, and training sessions.

## 📦 Dataset (UAVOD-10)

The model is trained to recognize 10 classes from aerial footage:
`building`, `cable-tower`, `cultivation-mesh-cage`, `landslide`, `pool`, `prefabricated-house`, `quarry`, `ship`, `vehicle`, `well`.

## 🛠️ Installation

The project uses [uv](https://github.com/astral-sh/uv) for fast and reliable Python environment management.

```bash
# Clone the repository
git clone <your-repo-url>
cd ABARS

# Install dependencies via uv
uv sync
```

## 💻 Usage (CLI Commands)

All scripts are executed via the `main.py` entry point using `uv run`.

### 1. Prepare the Dataset
Converts annotations and splits images into `images/` and `labels/` folders.
```bash
uv run main.py dataset_prepare
```

### 2. Hardware Test
Checks if GPUs are correctly recognized by PyTorch.
```bash
uv run main.py hw_test
```

### 3. Hyperparameter Tuning
Runs the genetic algorithm to find the optimal hyperparameters for a specific model size (`nano`, `small`, `medium`).
```bash
uv run main.py tune --model small
```

### 4. Train the Model
Trains the YOLO model. If tuning results exist for the chosen model, they are automatically loaded. 
```bash
# Train using tuned hyperparameters (if available)
uv run main.py train --model small --epochs 80 --patience 10 --name my_tuned_model

# Train using CV Filters (automatically generates physical dataset transparently)
uv run main.py train --model small --epochs 80 --patience 10 --name my_clahe_model --filter clahe grayscale

# Train using YOLO defaults (Baseline mode)
uv run main.py train --model small --epochs 80 --patience 10 --name my_baseline --baseline
```

### 5. Test MLflow Connection
A quick command to verify if MLflow is correctly logging to the local database without starting a full training run.
```bash
uv run main.py mlflow_test
```

## 📊 MLflow Dashboard

To view the training results, loss graphs, and compare experiments, use the provided bash script:

```bash
# If you are on your local PC:
./start_mlflow.sh

# If you are connected to a remote cluster via SSH:
./start_mlflow.sh cluster
```
Then open your browser at `http://127.0.0.1:5000`.

## 📂 Project Structure

- `dataset/`: Contains the UAVOD-10 raw dataset and the `uavod10.yaml` configuration.
- `YOLO/base_models/`: Pre-trained YOLO weights downloaded automatically by Ultralytics.
- `YOLO/trained_model/`: Output directory where your custom trained `.pt` files and metrics are saved.
- `YOLO/tuning_results/`: Stores the `.yaml` files generated by the tuning process.
- `jobs/`: SLURM `.sh` scripts to easily submit jobs to a cluster.
- `mlflow.db`: Local SQLite database storing all MLflow tracking data.
